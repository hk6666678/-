# 模型使用受控工具并默认禁止外发

模型适配器默认禁用外部调用与外部追踪上传。2026-11-18 用户授权在业务环境的 Agent 问答中使用阿里云百炼。启动时用 `-EnableBailianAgent` 为指定业务库开启该用途，同时校验已批准的模型配置、百炼地址与型号。业务环境的论文语义解析仍使用获准的本机模型。百炼凭证可通过 `-PromptBailianKey` 从本机终端隐藏输入，仅注入服务进程环境。

Agent 沿用当前用户权限，通过只读业务工具获取系统计算的结果及证据，不持有业务写入工具。该限制保留统一权限与追溯路径，避免把生成文本当成统计结果或专家评审；模型测试替身不构成真实智能功能的验收。
