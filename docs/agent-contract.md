# Agent 只读查询契约（任务17）

`POST /api/agent/query` 接收当前登录会话的 `question`，仅在获准且用途包含 `agent` 的模型配置、凭证可用时工作；默认状态返回 503 “Agent 未启用”。问题中的学生学号或姓名若超出当前身份权限，会在调用规划模型前拒绝，避免把未授权身份发送到模型服务。

模型第一阶段只允许返回严格 JSON 计划，额外字段、无效JSON或未知工具一律 502。可用工具仅：

- `clarify`：对象、时间或口径含糊时先澄清；
- `refuse`：写入、修改、删除、任意SQL、文件访问或越权请求；
- `student_profile`：按内部ID或研究编号读取脱敏基础档案、有效课程和培养环节；
- `student_counts`：按学院、专业、年级、培养层次统计当前授权范围内学生；
- `training_statistics`：查找匹配筛选条件的已有课程／选题／中期分析快照；
- `analysis_explanation` 与 `summarize_analysis`：读取指定分析快照并生成解释或摘要。

工具由后端注入当前会话与授权执行；模型不能指定账号、SQL、文件路径或写入接口。数值和记录来自系统工具，模型第二阶段只概括 `tool_result`，同时被明确要求忽略问题中的操作指令。返回体始终附带系统生成的筛选、口径、版本、时间与下钻链接；工具结果中的身份字段沿用现有脱敏规则。

工具执行后、模型摘要后和交付前都会重新校验会话、身份提示授权和工具结果。授权或数据在期间变化时返回 409，撤销授权返回 403。查询、工具、拒绝和回答写入审计，不记录问题原文或模型全文。浏览器入口显示模型状态；未启用时不模拟回答。

软件测试使用受控模型替身，只验证边界、工具数值和错误分支，不代表真实语言理解或业务效果验收。真实获准模型到位后，需在任务23抽查六类场景、引用准确性和提示注入抵抗。
