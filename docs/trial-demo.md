# 模拟试用交付说明

用户已确认本次以模拟试用版交付为完成范围；真实资料、专家规则及获准模型尚未具备，任务23保持待输入。

## 启动和演示

按根README安装依赖、构建前端、初始化个人管理员，运行Start-Aqp.ps1，访问 http://127.0.0.1:8000。没有生产默认密码。

1. 创建个人账号，分别授予维护、查看、分析、身份、导出和原件下载权限，系统管理员不自动获得业务权。
2. 下载四类模板，预览和确认合成数据；查看错误、待关联、纠错及统一学生档案。
3. 查看课程、选题和中期分析并下钻来源。规则只使用明确标注的合成配置，无依据时保留未知。
4. 上传可提取文字的合成PDF，等待worker解析；查看页序、比较、候选和人工复核版本。合成标签和规则不代表业务标准。
5. 导出结果、受控下载原件、撤销授权后重试，查看审计与旧分析过时标记。
6. 没有获准模型时Agent未启用是正确状态，不用固定回答冒充智能功能；本地论文文本解析仍可使用。
7. 按backup-restore.md停所有服务和worker后成套备份，恢复至新目录，重新登录核对档案、来源、原件、证据和复核。

## 合成样本与限制

按trial-validation.md命令重建小规模、全规模、错误文件及恢复验证包。本地data/check-samples含36个Excel和独立expected.json，不随Git交付，换机器需重新生成。冲突/同键变化样本须先确认正常样本后演示。

1000学生/30000课程/各2000选题中期/100论文/约5用户已实测。分析仍会排队，不承诺固定响应时间。详细环境和失败修复证据见trial-validation-scale.md，恢复覆盖与局限见trial-validation-restore.md。真实验收继续保留，不宣称模拟结果证明学术评价有效。
