# 交接文档模板

> 用途：跨会话、跨供应商或额度停止时交接。复制本模板至根目录 `HANDOFF.md` 对应章节（或整份替换后填写）。
> 规则依据 `quota-handoff.md`；集中上传依据 `github-sync.md`。

## 使用说明

- 所有 HEAD/SHA 填写后必须以 `git log -1`（或 `git log -1 <branch>`）核实，不得凭记忆；工作树以 `git worktree list` 核实。
- 区分三类状态，不得混写：**实现完成** / **模拟验证通过** / **真实业务验收**。
- 来源无法核实的代码或用户改动标注"未知"，不擅自提交、不 reset、不删工作树。
- 摘要不包含密钥、认证信息、学生隐私原文。
- 每个已完成任务一节检查点，**最新在最上**；旧节标题追加"（历史）"保留，不删除。

## 交接头

- 交接时间：YYYY-MM-DD HH:MM（时区）
- 根目录 / 集成分支：<路径> / <branch> @ <HEAD>（git log -1 核实）
- 交接原因：<额度<=5%停止 / 用户指示 / 阶段收口 / 其他>
- 官方额度：<短周期剩X%、周剩Y%（单次读数非实时监控）>；工具不可用时必须写明"本会话无法读取官方额度"，不得沿用旧读数冒充当前值。
- 同步状态：<仅本地未 push / 已集中 push 并在线核对（逐分支列远程SHA）/ 认证缺失仅本地>
