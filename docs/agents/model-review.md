# 模型相关改动的审查规则

改动涉及模型调用、Agent 权限、论文证据或模拟验收时，运行 README 中的离线验收命令，并沿实际调用顺序核对以下边界。

- **材料来源。** 检查普通业务请求是否在网络发送前被拒绝。百炼模拟验收应使用独立临时库和附件，只为脚本生成的固定请求授予临时权限。
- **工具读取、摘要发送和返回。** 检查各步骤使用的授权，并说明权限在哪一步发生变化、模型已收到哪些内容。发送前复查失败时核对调用次数。返回前复查失败时确认结果不会显示给用户。检查复查与派发之间是否仍可能发生撤权。
- **拒绝审计。** 涉及拒绝后的审计时，确认事务完成后管理员仍可查询事件，并检查事件只包含必要元数据。
- **论文引文。** 核对发给模型的页序以及返回引文与对应页原文的匹配，至少覆盖第 2 页。
