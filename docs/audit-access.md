# 审计访问与元信息范围

任务 20 的审计查询属于平台管理功能，只允许有效平台管理员调用。学院分析与维护角色不会因此获得查看全体审计的权限。此功能不授予学生数据查看、身份展示或原始附件下载权限。

审计页面可按操作者账号 ID、操作、起止时间和公开目标标识精确筛选，分页大小上限100。时间边界包含端点；结果按事件 ID 倒序。查询动作本身记入审计，查询结果不包含本次尚未写入的查询事件。

账号管理事件展示管理对象标识。其他业务事件目标转换为稳定 ref 标识，不返回原始学生标识、文件路径或标题；目标筛选使用相同公开标识，避免通过原始标识试探业务记录是否存在。自由文本和不在允许集合内的详情不返回；前后角色、状态、版本、数量、授权范围与结构化原因码可展示。原始业务记录应通过各业务模块的权限接口访问，而非审计页面。

旧版账号审计接口只返回账号与授权类事件，且详情使用同一元信息过滤规则。审计写入会移除常见密码、密钥、令牌、正文和身份字段；后续模块仍须遵守日志最小化原则，不主动把原始全文或秘密传给日志函数。
