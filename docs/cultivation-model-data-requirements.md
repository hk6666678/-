# 培养研究模型待补数据与口径

## 可先采用的导入字段和分析口径

以下为拟用字段。可按这个结构制作测试样例，正式统计使用业务部门提供的实际值和生效口径。

| 数据 | 建议字段 | 系统处理 |
| --- | --- | --- |
| 盲审送审 | 学号、送审批次、应交日期、实际提交日期、提交状态 | 同一批次内，实际提交日晚于应交日，或状态明确为未提交且已过应交日，才判定超期。状态未知时显示待核查。 |
| 论文与期刊评价 | 论文业务编号或 DOI、期刊、指标体系、评价年度、分区、影响因子 | 保留来源与年度，按论文编号关联。不同评价体系分别展示，缺失的指标留空。 |
| 专利转化 | 专利号、转化状态、转化日期、来源 | 按专利号关联，未知状态与明确未转化分别展示。 |
| 毕业与延期 | 学号、培养层次、预计毕业日期、实际毕业日期、学籍状态、统计日期、毕业去向 | 先保留原始日期和状态。正式毕业率、延期率使用学校确认的届别、分母和延期认定规则。 |
| 学科方向与参考资料 | 学科或专业代码、方向名称、资料编号、标题、摘要、来源与日期 | 可先做可解释的文本相似度筛查，显示命中依据；正式结论由专家核定。 |
| 论文与评语样本 | 样本编号、培养层次、专业、脱敏文本、优秀或普通标签、专家依据 | 可用合成样本验证流程。模型效果验证使用获准的真实样本。 |

## 模型 2 导师培养效能

- 同研究方向和同职称对标需要统一的研究方向分类、导师职称及其生效日期，以及可比单位的最低样本标准。现有比较采用授权范围内的同学院同类单位，并对评分指标使用同一规则版本。
- 毕业后影响力转化需要经许可关联的毕业去向及后续职业、科研或成果转化记录。需确认观察期、分母、追踪覆盖率和缺失处理。
- 综合效能排名需要专家确认各指标的权重、方向和缺项处理。当前提供分指标排名。

## 模型 3 培养质量影响因素

- 扩展回归需要有日期和统一口径的导师指导频率、国际交流、课题组环境等记录。正式推断前，应确认观测窗口、样本量、混杂因素和统计假设。
- Logistic 回归需要已核验的二分类结局，例如是否延期、是否流失，并需有结局的历史样本和独立验证数据。
- 现有多元线性回归取同学院、专业和届别的百分制选题及中期成绩与同规则版本模拟总分，完整案例少于五人时不计算。结果仅用于探索关联。

## 模型 4 延期与流失预警

- 延期及流失概率需要业务部门确认延期、转导师及退学等事件的定义，并提供应完成日期、实际结局、随访期和往届历史样本。正式启用前需在独立届别验证误报、漏报及不同群体的表现。
- 多指标控制图需要同一学生足够多的可排序重复观测及可比的评分口径。现有课程控制图和过程条件提醒，以及本次新增的已登记成果对比与学籍异动，均用于人工核查。
- 同届成果比较采用当前授权的同学院、同专业、同入学年份学生。结果受成果登记覆盖影响，统计值不表示对真实成果的完整追踪。
