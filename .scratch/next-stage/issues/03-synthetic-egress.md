# 强制隔离百炼模拟材料外发

审查发现默认业务库设置外部服务审批后可达模型客户端。用户要求隔离模拟数据库及附件，在出站前验证来源，并保留模拟 Agent 和论文验证流程。

测试覆盖普通服务连接检查、来源未经确认的 Agent 文本、上传的论文在模型客户端前被拦截，以及隔离流程仍可调用测试替身。

## Answer

默认业务服务拒绝外部目标。隔离脚本用临时数据库和附件目录，通过进程内客户端提交固定模拟请求，授权绑定库和百炼目标，并在单次请求结束后撤销。同一隔离客户端中的未知文本仍被拒绝。已移除旧启动器并重启普通服务。

全量回归 151 项通过，复审调整后的相关 7 项通过。类型检查与 Ruff 通过。规格复审未发现阻塞项，规范复审发现的重复回环分类和测试导入位置已修正。使用模型替身验证，本轮未请求百炼。
