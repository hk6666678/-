# 03 数据一致性交叉核对与三级分类标记

Status: ready-for-agent

新模块 `backend/aqp/data_quality.py`。

- `GET /api/consistency/checks?college=&major=`：对指定学院专业范围内当前授权可见的学生做交叉核对，每项返回检查说明、命中数和最多 50 条明细（研究编号与两侧来源）。无查看权限的来源类别标注"未核对"。
  检查项：课程记录与档案的学院专业不一致；选题中期记录与档案的学院专业不一致；来源记录姓名与档案姓名不一致（需身份授权）；学位论文的培养层次或学科与档案不一致；档案登记了导师姓名但无当前有效指导关系；有实际毕业日期但早于入学日期；盲审标记已提交但缺实际提交日期；学籍异动类型与异动时间缺其一；待关联记录计数。
- `GET /api/data-classification`：返回数据类别到三级分级的映射及依据，登录即可读取。
- 前端：数据纠错与维护页新增"数据一致性核对"与"数据分级"两个区块。
