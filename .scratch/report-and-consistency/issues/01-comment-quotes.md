# 01 评语原句查询

Status: resolved

`GET /api/external-assessments/keywords` 增加 `quotes` 参数：为真时按用户输入的关键词返回命中的句子片段（按句末标点与换行切分，单条截断 500 字，最多 100 条），每条带关键词、评语记录编号和论文版本编号。

- 权限与现有关键词统计一致：仅扫描当前可见且有下载授权的盲审评语；无下载授权的计入跳过数，不返回原文。
- 不返回学生姓名与学号。
- 不接入 Agent 工具。
- 前端：盲审与答辩页的关键词区增加"显示命中原句"选项，并按评语记录编号给出下钻位置。

## Answer

已实现。每条评语对每个关键词只返回首个命中句，整体上限 `QUOTE_LIMIT = 200`（超出时 `quotes_truncated` 为真，计数不受影响）。未传 `quotes` 时响应与原先完全一致。后端新增 6 项用例（命中句与编号、默认关闭、无下载授权不泄露原文、长句截断、上限、按论文版本过滤）；前端新增浏览器用例 `comment-quotes.spec.ts`。
