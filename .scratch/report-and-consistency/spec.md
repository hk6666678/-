# 正式报告、评语原句、课题组研究与数据质量

## 背景

2026-11-24 对照方案核对后，剩余"数据已在系统内、模拟数据可做"的四项缺口，用户指示全部实现：

1. 评语原句查询
2. 课题组规模与产出的关系、历届优秀学生成长路径共性（方案模块 5）
3. 数据一致性交叉核对、公开/内部/敏感三级分类标记（方案 4.1、4.4）
4. 三级报告 PDF/Word 排版导出（方案 5.3）

## 约束

- 不改权限模型与审计要求；新端点沿用对应来源类别的现有授权口径。
- 不发明业务标准：相关系数、均值差均为描述性统计，附样本量与局限，不作因果表述。
- "优秀学生"口径：论文样本标签（专家标注）为"优秀"的学生；对照组为标注"普通"的学生；"待评"不纳入。标签不足时不计算并说明原因。
- 评语原句只在页面端点提供，不接入 Agent 工具（工具结果会发往外部模型，扩大外发面须另行审批）。
- 数据分级为方案第四节规定的三级在系统数据类别上的映射，属于待业务确认的建议映射。
- PDF 导出依赖服务器中文字体；缺失时明确报错并提示改用 Word 或 Excel，不输出乱码文件。
- 全程合成数据验证；仅本地提交。
