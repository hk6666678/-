# 10: 正文附件与受控下载

**Status:** resolved

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 为选题／中期批次后补 PDF、DOCX，并按权限查看历史和下载。

**Blocked by:** 05 选题与中期导入

**规格覆盖:** 用户故事 23、24、67；AC13、AC22。

## Acceptance criteria

- [x] 附件绑定学号、环节和批次，保存文件版本与替换历史，不阻塞已有成绩分析。
- [x] 文件保存在受控目录，通过服务端校验后下载；不执行嵌入内容或文档指令。
- [x] 原始下载独立授权，检查文件全体内容涉及的学生范围和身份权限；不提供绕过权限的静态路径。
- [x] 建立可复用文件版本和证据访问契约，后续论文沿用。
- [x] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [x] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。
