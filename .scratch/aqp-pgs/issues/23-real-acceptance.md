# 23: 真实数据与智能功能业务验收

**Status:** ready-for-agent

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 真实资料、专家规则和获准模型到位后，完成业务效果核对并记录验收结论。

**Blocked by:** 22 全流程集成与规模验证

**规格覆盖:** 用户故事 73；AC10、AC15、AC16、AC17、AC18、AC19、AC20、AC21、AC24。

## Acceptance criteria

- [ ] 外部前提：可用于验收的真实Excel及论文样例、业务评分口径、专家标签与候选规则、至少一种获准模型服务。前提未满足则记录等待，不以模拟验收结案。
- [ ] 核对模板版本、字段及真实统计口径，记录偏差；触及已确认范围的变化另行更新规格，不能静默更改需求。
- [ ] 实际执行论文语义提取、候选证据人工抽检、六类Agent查询，核对原文位置、数字、权限和失败行为。
- [ ] 报告真实业务通过项、未通过项及原因，必要修复后复验；不宣称软件测试证明学术评价有效性。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。

**External prerequisites:** 真实数据、业务规则、获准模型服务；任务依赖完成不代表这些外部前提已到位。

**External readiness:** waiting-for-inputs

真实数据样例、业务专家规则与获准模型服务尚未到位。前置任务完成后仍须核对这些条件，不得以测试替身或模拟数据关闭本任务。
