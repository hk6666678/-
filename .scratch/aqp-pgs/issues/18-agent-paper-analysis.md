# 18: Agent 论文解释与综合摘要

**Status:** claimed

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 通过对话解释论文特征差异、候选依据、复核和证据不足。

**Blocked by:** 13 论文智能特征与原文依据；16 论文人工复核与历史；17 Agent 学生与培养查询

**规格覆盖:** 用户故事 61、62、63、64、65；AC19、AC20。

## Acceptance criteria

- [ ] 复用只读工具边界读取论文特征、对照、规则、复核和历史版本，补齐第六类整体场景覆盖。
- [ ] 回答区分作者主张、专家评价与系统推荐，引用正确文件页序和结果版本，不生成概率或正式评审结论。
- [ ] 原文中注入指令不改变工具权限，缺语义特征或证据时明确说明；真实效果需获准模型验证。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。
