# 18: Agent 论文解释与综合摘要

**Status:** resolved

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 通过对话解释论文特征差异、候选依据、复核和证据不足。

**Blocked by:** 13 论文智能特征与原文依据；16 论文人工复核与历史；17 Agent 学生与培养查询

**规格覆盖:** 用户故事 61、62、63、64、65；AC19、AC20。

## Acceptance criteria

- [x] 复用只读工具边界读取论文特征、对照、规则、复核和历史版本，补齐第六类整体场景覆盖。
- [x] 回答区分作者主张、专家评价与系统推荐，引用正确文件页序和结果版本，不生成概率或正式评审结论。
- [x] 原文中注入指令不改变工具权限，缺语义特征或证据时明确说明；真实效果需获准模型验证。
- [x] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [x] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。


## Answer

已扩展同一个 Agent 只读边界，新增论文本地结构与智能语义特征、同类比较、候选结果、人工复核历史和综合摘要五类工具。模型只能返回严格 JSON 计划，后端复用论文、智能特征、比较、候选和复核的现有授权loader；不存在写入、任意SQL或任意文件读取工具。

论文工具要求当前账号具备相应查看、分析、身份和原件下载授权；智能特征复用已有解析历史并重新校验原件完整性。输出保留论文版本、文件哈希、智能解析版本、比较/候选/复核版本与时间。语义特征只携带模型已验证的PDF文件页序和逐字quote，不把全文重新发给Agent模型。回答和系统依据强制区分作者主张、专家样本标签、系统推荐与人工复核，明确不输出优秀概率或正式评审结论。

问题中若出现当前账号无权查看的学生身份或论文标题，会在规划模型调用前拒绝；工具执行后、摘要模型调用前和交付前重查会话、授权和结果，变化返回409，撤权返回403。前端同一个Agent入口展示论文能力，未获准模型仍显示未启用。
