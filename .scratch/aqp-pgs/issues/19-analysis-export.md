# 19: 分析 Excel 导出与原始资料控制

**Status:** ready-for-agent

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 按当前范围导出培养和论文分析，同时严格区分原始资料下载。

**Blocked by:** 09 培养环节分析与条件提醒；15 候选规则与推荐依据

**规格覆盖:** 用户故事 66、67；AC22。

## Acceptance criteria

- [ ] 导出包含筛选、统计口径、生成时间、数据／规则版本及过时标记，遵守字段脱敏和学生范围。
- [ ] 覆盖培养分析与论文比较／候选结果；用户文本不能作为可执行表格公式。
- [ ] 验证原始 Excel、论文、选题／中期文件下载与导出不同授权，超范围或缺身份权不能下载原件。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。
