# 04: 课程导入与待关联记录

**Status:** ready-for-agent

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 导入课程记录，查看学生课程明细和基础档案缺失时的待关联状态。

**Blocked by:** 03 基础信息导入与学生档案

**规格覆盖:** 用户故事 7、9、10、11、15、16、18、20、25；AC02、AC03、AC05、AC06、AC07。

## Acceptance criteria

- [ ] 按课程模板和学号＋课程编号＋修读学期＋考核次数识别记录，合法空成绩与错误值分开。
- [ ] 无基础档案时仅保存待关联业务数据；基础补齐后自动核对并关联，身份冲突转人工处理。
- [ ] 已关联课程显示在档案；同课不同学期、重修和补考分别保留，重复提交不倍增。
- [ ] 预览及处理状态计数互斥且总数一致，内容变化先显示待确认，不自动更新。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。
