# 02: 授权配置与脱敏访问

**Status:** resolved

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 管理员配置数据类别、学生范围和操作权，用户看到与授权一致的内容。

**Blocked by:** 01 本机启动与个人账号

**规格覆盖:** 用户故事 3、4、5、6、27；AC01、AC09、AC18、AC23。

## Acceptance criteria

- [x] 提供授权管理页面，分别配置维护、查看、分析、身份展示、导出、下载、规则、标签和复核操作。
- [x] 在服务端校验权限，使用明确合成的示例记录验证研究编号展示、字段脱敏和范围隔离；后续导入复用该边界。
- [x] 授权撤销立即影响后续 API 和页面访问，审计记录授权变更；禁止仅靠隐藏按钮实现权限。
- [x] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [x] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。
