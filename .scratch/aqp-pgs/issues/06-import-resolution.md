# 06: 在线纠错与身份确认

**Status:** ready-for-agent

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 在待处理区修正四类导入错误、确认身份，并完成安全的再次提交。

**Blocked by:** 04 课程导入与待关联记录；05 选题与中期导入

**规格覆盖:** 用户故事 12、13、14、17；AC03、AC04、AC05。

## Acceptance criteria

- [ ] 四类模板均可查看原始错误行、修改值、重新校验和再次确认；原始行不可改写。
- [ ] 学号姓名冲突和同号多人提供人工处理，记录依据、处理人和时间；不自动合并正式档案。
- [ ] 仅提交新修复行，已成功行不重复处理；下载错误报告遵守身份、范围与字段权限。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。
