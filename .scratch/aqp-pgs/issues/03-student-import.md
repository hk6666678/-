# 03: 基础信息导入与学生档案

**Status:** resolved

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 下载基础模板、预览并确认导入，生成可筛选和追溯的学生档案。

**Blocked by:** 02 授权配置与脱敏访问

**规格覆盖:** 用户故事 7、8、9、10、11、12、18、25、26、36；AC02、AC03、AC06、AC09、AC12。

## Acceptance criteria

- [x] 按规格的基础模板字段和版本校验，记录来源部门、文件、批次、原始行、上传人和时间；预览不写正式档案。
- [x] 确认提交有效行，错误行保留待处理，完全重复跳过，身份及内容冲突隔离，不静默覆盖。
- [x] 学号按文本保留前导零；生成研究编号；档案筛选、详情与原始行下钻遵守权限。
- [x] 从首个正式记录开始保留修订与原始行，提交重试不重复创建；先提供小规模合成基础文件验证完整流程。
- [x] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [x] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。
