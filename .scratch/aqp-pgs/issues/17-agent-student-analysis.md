# 17: Agent 学生与培养查询

**Status:** resolved

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 在对话界面查询学生、统计人数和培养数据，解释图表并引用证据。

**Blocked by:** 09 培养环节分析与条件提醒；12 获准模型配置与连接状态

**规格覆盖:** 用户故事 57、58、59、60、62、63、64、65；AC19、AC20、AC21。

## Acceptance criteria

- [x] 通过受控只读工具实现六场景中的学生、人数、培养统计与图表解释，并从已有结果生成摘要。
- [x] 后端注入身份和授权，数字来自工具；回复带筛选条件、口径、版本、时间及下钻链接。
- [x] 含糊问题先澄清，越权拒绝，缺数据说明；不执行任意 SQL、文件访问、业务写操作或文档指令。
- [x] 未配置获准模型显示 Agent 未启用，撤销授权影响会话和引用访问；替身测试与真实调用验收分开。
- [x] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [x] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。


## Answer

已实现 `POST /api/agent/query` 和浏览器“Agent 查询”入口。获准且用途包含 agent 的模型先返回严格 JSON 只读计划，后端拒绝额外字段和未知工具；可用工具仅限澄清/拒绝、脱敏学生档案、授权范围内人数统计、已有培养统计读取、分析解释与摘要。数值和证据全部由服务端工具计算，模型只做计划与概括，用户问题中的指令不获得工具。

学生档案无身份权限时移除学号和姓名；统计仅返回当前授权范围；已有分析复用任务09快照 loader并重新校验 view/analyze。问题中若包含当前无身份权限的学号或姓名，会在规划模型调用前拒绝。工具执行前、摘要模型调用前和交付前都会重查会话、授权和工具结果；变化返回409，撤权返回403。回答后附加系统生成的筛选、口径、版本、时间和证据下钻链接。默认模型未启用返回503，浏览器显示“Agent 未启用”，不用模拟回答冒充。

## Validation

API 替身覆盖默认禁用、人数统计、脱敏档案和有效课程、培养统计、分析解释、已有结果摘要、含糊澄清、写入拒绝、任意SQL字段拒绝、无效模型计划、撤销分析授权、未授权身份不发送规划模型。Chrome 8090验证真实页面显示未启用并提交写操作问题后得到服务端503提示。
