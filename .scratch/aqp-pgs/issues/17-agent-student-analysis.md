# 17: Agent 学生与培养查询

**Status:** claimed

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 在对话界面查询学生、统计人数和培养数据，解释图表并引用证据。

**Blocked by:** 09 培养环节分析与条件提醒；12 获准模型配置与连接状态

**规格覆盖:** 用户故事 57、58、59、60、62、63、64、65；AC19、AC20、AC21。

## Acceptance criteria

- [ ] 通过受控只读工具实现六场景中的学生、人数、培养统计与图表解释，并从已有结果生成摘要。
- [ ] 后端注入身份和授权，数字来自工具；回复带筛选条件、口径、版本、时间及下钻链接。
- [ ] 含糊问题先澄清，越权拒绝，缺数据说明；不执行任意 SQL、文件访问、业务写操作或文档指令。
- [ ] 未配置获准模型显示 Agent 未启用，撤销授权影响会话和引用访问；替身测试与真实调用验收分开。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。
