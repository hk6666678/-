# 08: 课程统计与通过规则

**Status:** ready-for-agent

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 配置通过规则并查看可下钻、可追溯版本的课程分析。

**Blocked by:** 07 差异确认、更正与作废

**规格覆盖:** 用户故事 28、30、31、32、33、34、36、37、38、39；AC10、AC12。

## Acceptance criteria

- [ ] 规则由获授权人员确认并版本化；业务通过结果优先，无结果无规则为未知，空成绩不记零。
- [ ] 按可比课程和评分制度展示分布及不及格情况，明确考核记录与去重学生人数的区别。
- [ ] 通过率分母为已知状态记录；四通过、两不通过、两未知的八条样本显示约66.67%，全未知显示不可计算。
- [ ] 保存结果、数据与规则版本和证据；数据／规则变化使旧结果标记过时，重新分析生成新版本。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。
