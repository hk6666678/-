# 01: 本机启动与个人账号

**Status:** resolved

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 启动平台，在浏览器完成个人账号创建、登录、退出和停用。

**Blocked by:** None (can start immediately)

**规格覆盖:** 用户故事 1、2、69；AC01。

## Acceptance criteria

- [x] 使用已确认技术方案建立可本机启动、依赖锁定和数据库迁移的应用，交付可实际操作的账号页面。
- [x] 三类角色与兼任可保存；系统管理权不自动赋予业务数据访问权；停用账号后旧会话失效。
- [x] 登录与账号变更留审计，提供受控的首次管理员初始化方式，不内置公开固定密码。
- [x] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [x] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## Comments

2026-11-11：任务完成。6 个公开 API 测试、1 个 Chrome 浏览器生命周期测试通过，类型、静态检查及构建通过。审查发现均已修复并复核。首次管理员通过本机交互命令设置密码，无默认密码。后续细分业务授权由任务 02 实现。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。
