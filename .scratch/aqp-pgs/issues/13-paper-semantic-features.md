**Status:** ready-for-human

## Acceptance criteria

- [ ] 每个语义特征携带文件版本、模型及解析配置标识和可核验原文位置；缺失不补造。
- [ ] 作者创新主张与业务专家评价分开；部分特征失败不能显示为全部成功。
- [ ] 无模型时保留本地结果并提示智能解析未启用；超时、失败可追溯重试，不触发未授权网络回退。
- [ ] 替身验证边界和错误分支；使用获准模型后的原文抽检记录作为真实效果验收证据。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。


## Answer

软件实现完成；合成数据功能验证通过；真实获准模型语义效果待验。

- `POST /api/papers/{version_id}/semantic` 按当前全体学生维护、查看、身份、原始下载权限调用获准 papers 模型；`GET` 同路径查看独立、不可覆盖的尝试历史。结果与本地解析分表保存，重试产生独立尝试，原PDF版本不变。
- 四类特征分别记录可用、缺失、失败；PDF页序从1开始，quote必须逐字存在于对应页，否则拒绝该特征。保留模型名称、配置版本、解析配置、文件版本与hash。作者创新主张与未提供的专家评价明确区分。全文作为数据输入，不执行论文指令，不静默截断。
- 禁用时保留本地特征；连接／响应失败只记脱敏失败，无未获准回退。每次历史与证据访问重查权限、原件完整性。UI可触发提取／重试并查看历史和引用。
- API替身验证禁用、错误页序拒绝、部分结果、缺失、超时、不可覆盖历史及身份撤销；Chrome8043独立合成数据库验证上传、本地处理、禁用智能解析与历史；finally恢复授权。
- 当前无实际获准模型及业务论文，未宣称真实智能效果验收。后续需实际模型逐项抽检四类特征语义、对应PDF页序quote及遗漏率，保存审批模型标识与抽检记录。
