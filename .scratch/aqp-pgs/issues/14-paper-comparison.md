# 14: 专家样本标签与同类比较

**Status:** resolved

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 录入有来源的样本标签，查看优秀／普通论文的同类特征对比。

**Blocked by:** 11 论文上传与本地解析

**规格覆盖:** 用户故事 41、42、47、48、49、50、56；AC16、AC18。

## Acceptance criteria

- [x] 授权标签维护人员记录优秀／普通、业务确认人、确认依据及实际录入人；未标注论文保持待评。
- [x] 仅同培养层次、同学科／专业比较，支持年度筛选，展示组样本数、特征缺失数和有效分母。
- [x] 先比较已有本地特征；语义特征在其功能就绪后按相同契约加入，不因尚无模型阻塞本任务。
- [x] 无适当对照时展示不足，排除被评对象自身；文件或标签修订使关联比较过时，不覆盖历史。
- [x] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [x] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。

## Answer

已交付140迁移、独立标签历史与比较API、ComparisonPanel。标签包含专家确认人、依据与实际录入账号，独立labels授权；比较排除自身，限定同层次同学科，支持年度，明确待评/缺失/有效分母。文件、标签和特征变化使不可覆盖历史比较标记过时。所有读取重查当前范围，比较不返回正文身份，原始证据继续沿用下载授权；审计与拒绝审计已接入。

契约：[比较接口](../../../docs/comparison-contract.md)。任务15通过比较ID及证据文件/标签版本接入；模型未可用不阻塞基础统计，计数不构成优秀结论。真实专家标准仍需业务验收。

验证：50项后端测试通过；mypy、ruff、前端TypeScript/Vite构建通过；Chrome 8044独立合成标签/比较闭环通过（finally恢复授权）。已合并integration/aqp-trial（含任务07/13），合并提交a773086。
