# 15: 候选规则与推荐依据

**Status:** ready-for-agent

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 确认启用版本规则，对论文生成可解释的候选结果或证据不足提示。

**Blocked by:** 14 专家样本标签与同类比较

**规格覆盖:** 用户故事 50、51、52、53、56；AC17、AC18。

## Acceptance criteria

- [ ] 提供结构化规则配置，包含范围、特征条件、必要证据、样本要求、缺失策略、版本和业务确认来源。
- [ ] 只有对应授权人员可启用；无启用规则、对照不足或必要证据缺失不输出肯定候选结论。
- [ ] 逐项展示命中、未命中、证据不足、对照组与原文依据；规则变化生成新版本并使旧结果过时。
- [ ] 合成规则仅用于软件验证，不冒充专家批准规则，不生成未经验证优秀概率；无需等待模型即可验证本地特征规则。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。
