# 21: 本机备份恢复与任务恢复验证

**Status:** ready-for-agent

**Specification:** [AQP-PGS 第一版开发规格](../spec.md)

**What to build:** 维护人员成套备份并恢复数据和附件，浏览器中核验档案与证据。

**Blocked by:** 11 论文上传与本地解析

**规格覆盖:** 用户故事 69、70、71；AC25、AC14。

## Acceptance criteria

- [ ] 提供可执行的本机备份恢复流程及操作说明，保证数据库与原始附件版本一致。
- [ ] 恢复后登录、档案、原始来源和论文页序证据可访问；已存在的分析／复核版本也应保持关联。
- [ ] 持久化任务恢复或安全重试，不重复发布成功结果；验证使用隔离的恢复目标，避免覆盖现有工作数据。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。本任务拆分已于 2026-11-11 经用户确认发布。任务可执行性取决于前置任务及注明的外部条件，不由分诊标签单独决定。
