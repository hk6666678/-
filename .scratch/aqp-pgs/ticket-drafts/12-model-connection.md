# 12: 获准模型配置与连接状态

**Status:** draft

**What to build:** 在平台管理界面配置经批准的模型连接并查看启用或不可用状态。

**Blocked by:** 02 授权配置与脱敏访问

**规格覆盖:** 用户故事 64、69、73；AC21。

## Acceptance criteria

- [ ] 保留 LangChain，连接明确网络目标、允许数据范围与授权状态；凭证不回显、不写日志。
- [ ] 默认关闭外部模型和外部追踪；缺批准、缺配置或不可用时明确禁用，不自动回退到其他服务。
- [ ] 用测试替身验证禁用、失败与连接行为；真实连接验证需获准服务，不能把替身标为真实连接成功。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。
