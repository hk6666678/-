# 14: 专家样本标签与同类比较

**Status:** draft

**What to build:** 录入有来源的样本标签，查看优秀／普通论文的同类特征对比。

**Blocked by:** 11 论文上传与本地解析

**规格覆盖:** 用户故事 41、42、47、48、49、50、56；AC16、AC18。

## Acceptance criteria

- [ ] 授权标签维护人员记录优秀／普通、业务确认人、确认依据及实际录入人；未标注论文保持待评。
- [ ] 仅同培养层次、同学科／专业比较，支持年度筛选，展示组样本数、特征缺失数和有效分母。
- [ ] 先比较已有本地特征；语义特征在其功能就绪后按相同契约加入，不因尚无模型阻塞本任务。
- [ ] 无适当对照时展示不足，排除被评对象自身；文件或标签修订使关联比较过时，不覆盖历史。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。
