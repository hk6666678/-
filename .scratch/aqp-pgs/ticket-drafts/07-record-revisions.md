# 07: 差异确认、更正与作废

**Status:** draft

**What to build:** 查看已有记录的新旧差异，确认更正或按原因作废并查看历史。

**Blocked by:** 06 在线纠错与身份确认

**规格覆盖:** 用户故事 19、21、22；AC06、AC08、AC12。

## Acceptance criteria

- [ ] 四类业务记录均支持同键变化差异确认，保留原值、新值、来源与操作者；身份字段转人工身份确认流程，不自行合并。
- [ ] 基于当前预期版本确认，期间被其他用户修改则提示冲突，不能覆盖后续修订。
- [ ] 作废要求权限和原因，退出当前有效数据集但保留历史；无物理删除及整批回滚能力。
- [ ] 提供可供分析依赖追踪的数据修订标识，并通过公开 API 与历史页面验证。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。此为待确认草稿，尚未发布到正式任务目录。
