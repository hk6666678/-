# 11: 论文上传与本地解析

**Status:** draft

**What to build:** 上传论文 PDF，查看持久化解析进度、基础特征及页序证据。

**Blocked by:** 10 正文附件与受控下载

**规格覆盖:** 用户故事 40、43、44、45、46、70；AC14、AC15。

## Acceptance criteria

- [ ] 论文记录学生关联、标题、培养层次、学科／专业、年度及文件版本；元信息缺失不猜比较组。
- [ ] 本地提取可核验的文字、章节和参考文献信息，保留1起始的PDF文件页序；语义特征明确显示未提取。
- [ ] 任务排队、处理中、成功、失败可查；扫描、加密和损坏文件保留原因，支持替换和重试。
- [ ] 独立 worker 持久化任务，中断恢复不重复发布结果；证据链接遵守当前权限，文件替换保留旧引用。
- [ ] 在本任务涉及的页面、公开 API 和持久化行为间完成可演示闭环，权限与审计随该功能一起交付。
- [ ] 使用已确认测试边界验证外部行为；测试数据清楚标为合成，测试替身不计真实模型验收。

## 实现约束

遵循 AQP-PGS 第一版开发规格、项目术语和架构决策；不扩大第一版范围。涉及的修订、证据与原始文件不得静默覆盖。此为待确认草稿，尚未发布到正式任务目录。
